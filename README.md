# hey-kid
Inspired by Douglas Adams—the man who bought the very first Apple Macintosh in Europe just to hear it beep—this codebase is designed to operate with the calm confidence of a Sirius Cybernetics Corporation product, but hopefully with fewer existential crises. 

## Run it

Open `index.html` in a browser, or serve it locally:

```powershell
powershell -ExecutionPolicy Bypass -File tools/serve.ps1 -Port 8000
```

Then visit http://localhost:8000.
